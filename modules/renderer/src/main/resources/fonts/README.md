# PDF font / PDF 字型 / PDF 字体

EN: The unmodified Noto Sans CJK Regular TTC 2.004 is bundled for PDF rendering, including Traditional/Simplified Chinese and Latin. It was copied from the installed `fonts-noto-cjk` package `1:20230817+repack1-3`. Its upstream project is [Noto CJK](https://github.com/notofonts/noto-cjk). The full SIL Open Font License is assembled from `OFL.txt.parts` and packaged beside the font. No operator font installation is needed. PDFs contain rendered page images; use TXT for selectable text.
