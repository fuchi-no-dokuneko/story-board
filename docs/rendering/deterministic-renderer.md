# Deterministic rendering

EN: Rendering uses an immutable revision and inclusive range. LF joins captions and text; offsets count Unicode code points. Metadata resolves from scene seeds and preceding blocks. PDF output retains deterministic A4 layout, font rendering, image bytes, and captions.

繁體中文：渲染使用不可變修訂與包含端點的範圍。文字與圖說以 LF 連接，位移按 Unicode 字碼計算。後設資料由場景初始值及前文解析。PDF 保留確定性 A4 版面、字型、圖片及圖說。

简体中文：渲染使用不可变修订与包含端点的范围。文字与图注以 LF 连接，偏移按 Unicode 码点计算。元数据由场景初始值及前文解析。PDF 保留确定性 A4 版面、字体、图片及图注。
