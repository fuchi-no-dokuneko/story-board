# Monitor submissions

EN: Monitor packets contain immutable local context and fingerprints. Submissions bind evidence and at most five affected blocks to that packet. Findings and proposals are stored separately from canonical history; stale status is derived from current revision state.

繁體中文：監測封包包含不可變局部上下文及指紋。提交將證據與最多五個受影響區塊綁定該封包。發現與提案和正式歷史分開保存；過期狀態由目前修訂推導。

简体中文：监测封包包含不可变局部上下文及指纹。提交将证据与最多五个受影响区块绑定该封包。发现与提案和正式历史分开保存；过期状态由当前修订推导。
