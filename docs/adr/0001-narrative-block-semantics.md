# Narrative blocks

EN: A novel contains chapters, scenes, and immutable block versions. Text blocks contain one or two complete sentences, at most 100 graphemes, and one direct speaker. Image blocks reference immutable PNG/JPEG artifacts; split, merge, and extend remain text-only operations.

繁體中文：作品由章節、場景及不可變區塊版本組成。文字區塊包含一至兩個完整句子，最多一百個字素與一位直接發言者。圖片區塊參照不可變 PNG/JPEG；拆分、合併及延伸僅適用文字。

简体中文：作品由章节、场景及不可变区块版本组成。文字区块包含一至两个完整句子，最多一百个字素与一位直接发言者。图片区块引用不可变 PNG/JPEG；拆分、合并及延伸仅适用文字。
