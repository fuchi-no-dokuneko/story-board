# Stable identities

EN: Prefixed UUIDv7 identities remain stable across movement. Fractional ordering keys determine position; deterministic rebalance handles exhausted gaps. A one-to-one rewrite retains the block ID and creates a new block-version ID.

繁體中文：帶前綴 UUIDv7 身分在移動時保持穩定。分數排序鍵決定位置，空隙耗盡時使用確定性重新排序。一對一改寫保留區塊 ID，並建立新區塊版本 ID。

简体中文：带前缀 UUIDv7 身份在移动时保持稳定。分数排序键决定位置，空隙耗尽时使用确定性重新排序。一对一改写保留区块 ID，并创建新区块版本 ID。
