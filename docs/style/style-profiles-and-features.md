# Style profiles

EN: Profiles bind a novel and corpus provenance. Immutable profile content uses the existing feature channels and calibration. Append-only lifecycle transitions move DRAFT to CALIBRATING, READY, and DEPRECATED; only eligible READY profiles can gate rewrite proposals.

简体中文：风格设置绑定作品与语料来源。不可变设置内容使用既有特征通道与校准。生命周期事件仅追加，从 DRAFT 经 CALIBRATING、READY 至 DEPRECATED；只有合格 READY 设置能触发改写提案。
