# Preview validation

EN: Preview is deterministic and has no storage writer. It returns normalized operations, candidate information, differences, rendering, warnings, and violations. Existing golden cases cover valid and rejected text, metadata evidence, presence events, and safe split anchors.

繁體中文：預覽具確定性且沒有儲存寫入器，回傳正規化操作、候選資訊、差異、渲染、警告與違規。既有黃金案例涵蓋有效與拒絕文字、後設資料證據、出入事件及安全拆分錨點。

简体中文：预览具确定性且没有存储写入器，返回规范化操作、候选信息、差异、渲染、警告与违规。既有黄金案例覆盖有效与拒绝文字、元数据证据、出入事件及安全拆分锚点。
