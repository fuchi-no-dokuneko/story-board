# Canonical transfer

EN: Revision export carries one genesis revision; package export carries linear history, operations, and portable artifacts. Imports validate the complete document and replay before atomic storage. Image-bearing history uses packages so the immutable image bytes travel with descriptors.

繁體中文：修訂匯出包含單一初始修訂；封裝匯出包含線性歷史、操作及可攜產物。匯入先驗證完整文件與重播，再原子儲存。含圖片歷史使用封裝，讓不可變圖片位元組與描述一同傳送。

简体中文：修订导出包含单一初始修订；封装导出包含线性历史、操作及可携产物。导入先验证完整文档与重放，再原子存储。含图片历史使用封装，让不可变图片字节与描述一同传送。
